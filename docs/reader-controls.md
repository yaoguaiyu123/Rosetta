# 阅读空间与操作修复

日期：2026-10-01。先将 `feat/html-typesetting` 快进合并到 `main`（`7bb83aa`），再在 `codex/reader-space-navigation` 上修复。

## 改动

- 桌面工具栏合成一行，全文译本操作保持紧凑的第二行；移除重复的大标题、介绍及译本标签栏，缩小底部状态栏。
- 目录仅使用 PDF 原有书签。新文档清理旧目录并默认打开侧栏，保留目录开关；窄屏使用侧栏抽屉，避免旧样式直接隐藏目录。没有书签时不生成章节或页码列表。
- 原文阅读器加载书签，译本阅读器不重复加载。明确设置 Vue 布尔属性默认值，确保原文的书签加载不会被关闭。
- 在应用内打开 PDF 后，以非被动的捕获监听器处理 Ctrl／Shift＋滚轮并取消浏览器默认行为。普通滚轮照常滚动；设置弹窗不截获。兼容 Chromium 对 Ctrl 滚轮的小滚动量归一化。
- PDF 缩放范围 25%–300%，每档 5%；从适应宽度的任意比例开始时，以显示的百分比步进。高频事件按动画帧合并，保持已有页码与页内位置恢复逻辑。

## 验收

- 使用 417 页的 Machine Learning 教材验证内置书签、默认展开的 23 行、跳转至第 7 页、收起再展开，以及划词／全文往返保留目录和页码。
- MobileNetV3 原文没有书签，确认不显示目录侧栏或目录按钮。
- 使用 Attention 已有的 mono／dual 配对验证显示和缩放，没有调用翻译接口。
- 浏览器通过 `Input.dispatchMouseEvent` 发送真实 Ctrl／Shift 滚轮事件：事件被取消，PDF 百分比改变，工具栏尺寸、视口宽度与设备像素比保持不变。普通滚轮实际改变文档滚动位置，PDF 百分比不变。
- 1440×960 视口下，全文阅读区域约占高度 89%，主工具栏 46px；750×900 下阅读区域约占 85%。占比计算的是 PDF 滚动视口，包含页间留白，不是 PDF 正文的字形面积。
- 通过类型检查、构建和缩放回归测试。验收浏览器无控制台错误、未捕获异常或界面错误提示。
- 另跑现有译本回归脚本，确认 mono／dual 切换、划词／全文往返，以及窄屏适应宽度后仍保留第 3 页；没有发出翻译请求。

复用浏览器验收脚本：`.workbuddy/tools/verify-reader-controls.mjs`。参数依次为带书签 PDF、无书签 PDF、已有完整译本配对的原文 PDF、截图前缀；可通过 `APP_URL`、`CDP_PORT` 指定独立服务与浏览器。
