# PDF 高亮

- 选择工具：划词翻译；高亮工具：拖选文字添加黄色高亮；橡皮擦：点击一条高亮擦除。
- 原文、中文单版和中英对照版都能编辑。中英对照文件是引擎生成的一份 PDF，左右两部分都能标注。
- 支持多行、跨页选区。一次划选为一次撤销；点击擦除为一次撤销。
- Ctrl+Z 撤销上一步；Ctrl+S 或保存按钮写入当前 PDF。保存后撤销会再次标记为未保存，需再次保存才能反映到磁盘。
- 编辑仅存在内存中，退出、刷新不自动保存。切换阅读模式保留当前文档的编辑；切换到另一份 PDF 或另一种译本前会提示丢弃未保存编辑。
- 从「打开 PDF」使用 Edge/Chrome 的文件选择器打开时，应用保留当前会话的文件句柄，保存时申请写权限。文件句柄不会持久化，重启后需重新打开 PDF。
- 拖入的文档、生成的译本或普通文件上传没有写句柄，首次保存会选择位置；可以选择原文件覆盖。浏览器没有文件写入接口时只会下载含高亮的 PDF，不能自动修改原文件。
- 保存使用 PDF.js 原生标准 Highlight 批注和增量 PDF 写入，不重新排版正文。支持擦除重新打开后已有的标准高亮；图片里烘焙的颜色和非高亮批注不属于橡皮擦范围。

验证覆盖：真实鼠标多行选区、保存前原始字节不变、保存后用独立 PyMuPDF 重新读取批注、保存后撤销并再次保存、已有高亮的擦除/撤销、125% 缩放、90 度旋转页及非零裁切边界。正文、书签、链接、页面旋转和裁切设置保持完整。验收使用自建文档及浏览器隔离存储，不修改用户论文。
